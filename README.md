# JavaScript Projects

A collection of JavaScript projects developed to strengthen my programming skills, understand web development fundamentals, and gain practical experience building interactive applications.

## Technical Skills

- **Languages:** JavaScript, HTML, CSS
- **Libraries:** Axios
- **Web Development:** DOM Manipulation, Event Handling, HTTP Requests, API Integration
- **Programming Concepts:** Functions, Conditional Logic, Loops, Arrays, CRUD Operations
- **Tools:** Git, GitHub, Visual Studio Code

## Projects

| Project | Description | Skills Demonstrated |
|---|---|---|
| Basic Calculator using Methods | Calculator implementing basic arithmetic operations | JavaScript, Functions, Methods |
| Dog and Cat HTTP Requests using Axios | Retrieves cat and dog facts using HTTP requests | Axios, APIs, HTTP Requests |
| Guessing Game | Interactive number guessing game | JavaScript, Conditional Logic, Game Logic |
| Simon Says Game | Interactive memory game using the DOM | DOM Manipulation, Event Handling, JavaScript |
| Todo List | Basic task management application | JavaScript, Arrays, CRUD Operations |
| Todo List using DOM | Adds and deletes tasks dynamically | DOM Manipulation, Event Listeners |

## Key Learning Outcomes

- Developed interactive web applications using JavaScript.
- Practised DOM manipulation and event-driven programming.
- Integrated external APIs using Axios.
- Strengthened problem-solving and programming fundamentals.
- Used Git and GitHub for version control and project management.
